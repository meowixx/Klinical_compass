# Пример датасета ИИ

`ai_patient_dataset.sample.csv` содержит только синтетические записи. Он показывает ожидаемую структуру будущей обезличенной выгрузки и не подходит для клинического обучения или проверки эффективности.

Идентификатор пациента должен быть псевдонимом. ФИО, телефон, адрес, MAX ID и номер карты в датасет для обучения не включаются. Разделение обучающей и тестовой выборки выполняется по пациентам, чтобы записи одного человека не попадали одновременно в обе выборки.
