# Запуск проекта для жюри

Проект рассчитан на Windows 10/11. Для первого запуска нужен интернет и около 5 ГБ свободного места.

## Первый запуск

1. Скачайте репозиторий и распакуйте его в папку без системных ограничений.
2. Запустите двойным щелчком `SETUP_AND_START.cmd`.
3. Скрипт установит Python 3.12, Node.js LTS и Ollama, создаст локальную SQLite-базу, загрузит Qwen и откроет сайт.
4. При запросе Windows разрешите установку приложений.

Повторно проект запускается файлом `start-project.cmd`. Для остановки выберите `S` в его окне или выполните `start-project.cmd stop`.

Сайт: http://127.0.0.1:3125

FastAPI и Swagger: http://127.0.0.1:8000/docs

Все стартовые сведения вымышлены и хранятся только в локальном файле `data/clinical_compass.db`.

## MAX-бот

Сайт и FastAPI работают без ключа MAX. Для демонстрации настоящего бота создайте файл `BotMax/MaxAPI.txt` и поместите в него API-ключ одной строкой. Ключ не входит в Git и не выводится в журналы. После этого перезапустите проект.

## Если автоматическая установка запрещена

Установите вручную Python 3.12, Node.js LTS и Ollama, затем снова запустите `SETUP_AND_START.cmd`. Модель Qwen работает на CPU и NVIDIA GPU; видеокарта не обязательна, но без неё ответы формируются медленнее.
